Nisse

A private household assistant

What Nisse is

Nisse is a personal assistant that Ethan Brown runs for his own household. It helps two family members plan and run the home: keeping a shared household task sheet up to date, managing the family calendar, and sending email on their behalf when they ask it to. Nisse is not a public product. It is not offered to anyone outside the household, and there is no sign-up.

How Nisse uses Google

Each household member signs in with their own Google account and approves only the access below. Nisse uses that access only to carry out a request the signed-in person makes.

  • Google Sheets: read and update the household's own spreadsheets, such as the shared task and planning sheet.
  • Gmail (send only): send an email from the person's own Gmail account when they ask Nisse to send it. Nisse cannot read the person's mailbox with this access.

Nisse runs on a private server on the household's own private network. It does not sell, advertise with, or share Google user data.
