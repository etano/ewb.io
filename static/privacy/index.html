Nisse Privacy Policy

Effective November 15, 2026

This policy explains how Nisse, a private household assistant operated by Ethan Brown, accesses, uses, stores, and shares data, including data received from Google APIs. Nisse is used only by members of Ethan Brown's household. It is not offered to the public.

Data Nisse accesses

When a household member connects their Google account, Nisse requests only these permissions:

  • Google Sheets (spreadsheets, spreadsheets.readonly): to read and update spreadsheets the user works with, such as the household task and planning sheet.
  • Gmail send (gmail.send, gmail.send.self): to send email from the user's own Gmail account. These permissions allow sending only. They do not let Nisse read, search, or delete the user's email.

Nisse also receives the text of requests the user makes to it, such as "add this task to the sheet" or "email this note to me."

How Nisse uses data

Nisse uses Google user data only to perform the action the signed-in user asked for: reading or writing a cell range they asked about, or sending an email they asked it to send. Nisse does not use Google user data for advertising, does not sell it, and does not use it to build user profiles.

To understand a request, Nisse may send the request text, and any spreadsheet content needed to answer it, to an AI model provider (such as Anthropic) for processing. Nisse does not allow Google user data to be used to train AI models.

Storage and retention

  • OAuth tokens are stored on Nisse's private server, on the household's private network, and are used only to make the requests described above.
  • Nisse keeps a log of requests and actions on that private server so the household can review what was done. These logs are not shared with anyone outside the household.
  • Email sent through Nisse is stored in the user's own Gmail Sent folder by Google. Nisse does not keep a separate copy of email content beyond its request log.

Sharing

Nisse does not sell, rent, or share Google user data with third parties, except the AI model processing described above, which happens only to carry out the user's request. Nisse does not transfer Google user data for any other purpose.

Google API Services User Data Policy

Nisse's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your choices

You can disconnect Nisse at any time from your Google Account at myaccount.google.com/connections. After you disconnect, Nisse can no longer access your Google data. To ask for deletion of stored tokens or logs, contact the operator below.
